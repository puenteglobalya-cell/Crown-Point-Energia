# Cómo cambiar tu contraseña — Portal Crown Point Energia

## Si ya tenés acceso al portal

1. Iniciá sesión en el portal: **https://crown-point-energia.vercel.app/portal**
2. En el menú, entrá a **Mi Cuenta** (`/portal/mi-cuenta`).
3. Buscá la sección **Cambiar contraseña**.
4. Completá los tres campos:
   - **Contraseña actual**
   - **Nueva contraseña**
   - **Confirmar contraseña**
5. Si necesitás verificar lo que estás escribiendo, tocá el botón **Mostrar** al lado de cada campo (se cambia a **Ocultar** para volver a tapar la contraseña).
6. Confirmá el cambio. La próxima vez que inicies sesión, usá la nueva contraseña.

## Si no podés entrar (olvidaste la contraseña o es tu primer ingreso)

1. En la pantalla de login del portal, tocá **¿Olvidaste tu contraseña?**
2. Ingresá tu email y vas a recibir un correo desde Crown Point Energia con un enlace para restablecerla.
3. Si sos un usuario invitado por un administrador, vas a recibir directamente un email de invitación con un enlace para crear tu contraseña por primera vez.
4. Ese enlace te lleva a una pantalla donde definís tu nueva contraseña.

## Si el administrador te generó el acceso manualmente

En algunos casos (por ejemplo, si el envío automático de correos falló), el administrador puede compartirte el enlace de acceso directamente por otro medio. Si te llega un enlace así:

1. Abrilo en el navegador.
2. Vas a llegar a la pantalla de **restablecer contraseña**.
3. Definí tu nueva contraseña y confirmá.
4. A partir de ahí, ya podés usar **Mi Cuenta** para cambiarla cuando quieras, como se explica arriba.

## ¿A quién contactar si tenés problemas?

Si no te llega el email de invitación/recuperación o el enlace no funciona, contactá al administrador del portal para que te genere un nuevo enlace de acceso.
